# Support

- **Anomalie reproductible** : utilisez le modèle d’issue « Rapport d’anomalie » sans joindre de données sensibles.
- **Évolution** : utilisez le modèle « Demande d’évolution ».
- **Vulnérabilité** : suivez impérativement [SECURITY.md](SECURITY.md).
- **Licence, installation ou accompagnement contractuel** : contactez Jessy System par votre canal professionnel habituel.

Précisez toujours la version de Sodium, la version de PHP, le navigateur et les étapes permettant de reproduire le comportement.
