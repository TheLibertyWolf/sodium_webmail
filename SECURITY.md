# Politique de sécurité

## Versions prises en charge

| Version | Prise en charge |
|---|---|
| Dernière version publiée | Oui |
| Versions antérieures | Non, sauf accord contractuel |

## Signaler une vulnérabilité

Ne créez pas d’issue publique. Utilisez de préférence un avis de sécurité privé GitHub depuis l’onglet **Security** du dépôt, ou contactez Jessy System par votre canal contractuel habituel.

Indiquez la version, le contexte, les étapes de reproduction, l’impact estimé et, si possible, une proposition de correction. N’incluez aucune donnée réelle d’utilisateur ou de messagerie. Un accusé de réception et les modalités de suivi seront communiqués après analyse.

Toute recherche doit rester limitée à une instance vous appartenant ou pour laquelle vous disposez d’une autorisation écrite. L’accès non autorisé, l’exfiltration de données, la perturbation du service et la divulgation avant correction sont interdits.
