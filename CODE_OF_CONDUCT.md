# Code de conduite

## Notre engagement

Les échanges autour de Sodium doivent rester professionnels, accueillants et respectueux, quels que soient l’expérience, l’identité, l’origine, la langue, la situation ou le point de vue des participants.

## Comportements attendus

- formuler des retours précis, constructifs et centrés sur le projet ;
- accueillir les questions de bonne foi et respecter les désaccords ;
- protéger les informations confidentielles et les données personnelles ;
- reconnaître les contributions et accepter les décisions de maintenance.

Le harcèlement, les attaques personnelles, les propos discriminatoires, la divulgation d’informations privées et tout comportement perturbant délibérément le projet sont interdits.

## Application

Un comportement inapproprié peut être signalé confidentiellement à Jessy System par le canal contractuel ou professionnel habituel. Les responsables du projet peuvent modérer, masquer ou refuser une contribution et limiter l’accès d’un participant. Les signalements sont examinés avec discrétion et impartialité.

Ce code s’applique aux espaces du projet et aux échanges publics ou privés effectués au nom de Sodium.
